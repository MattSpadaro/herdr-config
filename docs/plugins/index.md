# Plugins

- [Monokai](./monokai.md) - Monokai themes and a Monokai copy of Herdr's main layout; the visual base
- [Agent Ask](./agent-ask.md) - Asks panel and tab bar that detect and answer agent questions
- [Agent Columns](./agent-columns.md) - Board of agents by status; mods hosted by the base layout
- [Flockbook](./flockbook.md) - Agent conversation as chat, embedded per terminal in the base layout; Rust helper built from source
- [Better Changes](./better-changes.md) - Git panel; diffs open in one centre tab per space; replaces Herdr's Changes panel
- [Better Icons](./better-icons.md) - Material Icon Theme pack read by Better Changes
- [filetree](./filetree.md) - File tree with git status, filter and previews; replaces Herdr's Files panel in the base layout
